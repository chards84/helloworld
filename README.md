# ASCII Art Printer

โปรแกรม Python สำหรับแสดงข้อความ ASCII Art บนหน้าจอ Console

## ตัวอย่างการทำงาน

เมื่อรันโปรแกรม จะพิมพ์ข้อความ "Hello World" และแสดง ASCII Art ตามที่กำหนดไว้ในตัวแปร `text`

## โครงสร้างโค้ด

```python
print("Hello World")

test = ""

text = """
ASCII ART
"""

print(text)
```

### คำอธิบาย

* `print("Hello World")` แสดงข้อความต้อนรับ
* `test=""` สร้างตัวแปรว่าง (ปัจจุบันยังไม่ได้ใช้งาน)
* `text="""..."""` เก็บข้อมูล ASCII Art แบบหลายบรรทัด
* `print(text)` แสดง ASCII Art ออกทาง Console

## วิธีใช้งาน

1. ติดตั้ง Python 3
2. บันทึกโค้ดเป็นไฟล์ `main.py`
3. รันคำสั่ง

```bash
python main.py
```
